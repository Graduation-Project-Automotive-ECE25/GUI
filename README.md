Graduation project GUI (Qt Creator) subteam repository

This QML_based project produces a responsive GUI that supports any screen size and provides several features
involving speed guage, RPM guage, responsive turn signals, and multiple interactive buttons
like opening attached camera to the system, opening terminal in home directory of you device, 
project-definision sound button (could be modified), and reboot button.
In addition, it provides a simple interactive map with detecting your current location based on GPS module handler.
It also handels warning messages passed through Machine-Learning modules that are integrated with the system and displays them
in a separate page.
